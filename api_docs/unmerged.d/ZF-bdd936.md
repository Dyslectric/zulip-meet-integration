**Feature level ZF-bdd936**

* `POST /calls/jitsi/create`: Added new endpoint for creating an
  authenticated Jitsi Meet call. When the server is configured with JWT
  credentials for its Jitsi deployment, this endpoint verifies that the
  user is a member of the conversation the call belongs to, derives an
  unguessable room name for that conversation, and returns a join URL
  carrying a short-lived token scoped to that room. Previously, Jitsi
  room names were generated by clients and rooms were unauthenticated.

* [`POST /register`](/api/register-queue): Added
  `server_jitsi_jwt_enabled` boolean field, indicating whether the
  server can mint authenticated Jitsi links. Clients should call
  `POST /calls/jitsi/create` when it is true, and continue generating
  room names themselves when it is false.
